# Git commands

Run these commands from the repository root:

```bash
git init
git add .
git commit -m "Add Flutter lab experiments 1 to 12"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/flutter-lab-experiments.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username. If the GitHub repository already has a README or other initial commit, pull/reconcile that history before pushing.
